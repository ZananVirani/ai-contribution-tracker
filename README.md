# 🎓 AI Contribution Tracker

Welcome to the **AI Contribution Tracker** – a project that reimagines how class participation is evaluated in large-format undergraduate business courses like **Business 1220** and **2257**.

In both courses, participation accounts for **10% of a student’s final grade**, and instructors are required to record a *contribution score* for each student after every class. This process is traditionally manual, repetitive, and time-consuming — especially when dealing with multiple sections and hundreds of students.

## 🚀 What We Built

The AI Contribution Tracker aims to **automate the first pass** of this process. Instead of professors manually entering scores for every student, our system listens to each student's contribution during class and assigns a preliminary score using AI. This shifts the professor’s role from *inputter* to *reviewer*. Instructors can still view, adjust, or override any score, but the tedious initial work is already done.

By introducing automation into the workflow, we help save valuable faculty time, reduce subjectivity in initial scoring, and improve consistency across sections and instructors.

## 💻 Tech Stack

- **Frontend**: TypeScript (Next)
- **Backend**: Python (FastAPI)

## 🧠 Why It Matters

The classroom at Ivey is built on discussion-based learning. With our tool, we ensure that the **quality and quantity of participation** are fairly and efficiently recognized — while freeing up instructors to focus on what really matters: **teaching and student engagement**.
